# python_text_diff_tool

## Project Name
Python Text Diff Utility

## Description
`python_text_diff_tool` is a simple yet powerful command-line utility written in Python that allows users to compare two text files and display their differences in a clear, colorized format. It's designed to be straightforward to use and relies solely on Python's standard library, making it highly portable. This tool is ideal for quickly identifying changes between different versions of text documents, configuration files, or code.
