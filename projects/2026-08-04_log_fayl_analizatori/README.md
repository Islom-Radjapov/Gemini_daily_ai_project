# Python Log File Analyzer

## Project Name
Log File Analyzer

## Project Description
The Python Log File Analyzer is a command-line utility designed to read, parse, and analyze log files. It helps users quickly gain insights into their application logs by providing statistics such as log level distribution, total lines processed, and the time range of logs. Furthermore, it allows users to filter log entries based on specific log levels or keywords within the log messages. This utility is built exclusively using Python's standard library, making it lightweight and easy to deploy without external dependencies.
