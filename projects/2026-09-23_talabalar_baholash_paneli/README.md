# student_grades_dashboard

## Project Name: Student Grades Dashboard

## Description
This project is a single-page HTML dashboard designed to visualize student performance data. It provides a quick overview of key metrics such as total students, average grade, top/bottom performers, and a detailed breakdown of individual student grades and attendance. The dashboard is built with a clean, modern, and professional user interface using only standard HTML, CSS, and JavaScript. All data is dynamically generated as fake data within the JavaScript.

## How to Run
To run this project, simply save the provided `student_grades_dashboard.html` file to your local computer. Then, open the `student_grades_dashboard.html` file in any modern web browser (e.g., Chrome, Firefox, Safari, Edge). No server or special setup is required.

## Features
*   **Dynamic Data Generation:** Automatically generates a set of fake student data upon loading, including names, scores, and attendance percentages.
*   **Summary Statistics:** Displays key performance indicators at a glance:
    *   Total number of students.
    *   Overall average grade.
    *   Highest recorded score.
    *   Lowest recorded score.
*   **Detailed Student Table:** Presents individual student data in a well-formatted, sortable (visually) table, showing their name, letter grade, percentage score, attendance, and a performance status.
*   **Visual Grade Distribution:** Shows a graphical representation (using CSS bars) of how grades are distributed across different categories (A, B, C, D, F).
*   **Modern UI/UX:** Features a clean, responsive (basic desktop layout), and professional design with an intuitive layout, card-based summaries, and clear typography.
*   **Pure Frontend:** Built entirely with HTML, CSS, and JavaScript within a single HTML file, requiring no external libraries or frameworks.
