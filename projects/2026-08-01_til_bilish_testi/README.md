# til_bilish_testi

## Project Name
Til Bilish Testi (Language Proficiency Quiz)

## Project Description
This is an interactive web-based quiz application designed to test general language proficiency. It features a series of multiple-choice questions covering various aspects of language, such as grammar, vocabulary, and sentence structure. The quiz provides immediate feedback on answers, tracks the user's score, and offers a clear result summary at the end. The entire application is contained within a single HTML file for easy deployment and use.

## How to Run
1.  **Save the file**: Copy the content of `index.html` into a file named `index.html`.
2.  **Open in Browser**: Open the `index.html` file using any modern web browser (e.g., Chrome, Firefox, Safari, Edge).

The quiz will load automatically, and you can start answering the questions.

## Features
*   **Interactive Interface**: Engaging user experience with clear questions and selectable answer options.
*   **Multiple-Choice Questions**: Features at least 10 (currently 12) carefully crafted questions to test various language skills.
*   **Immediate Feedback**: Users receive instant visual feedback (correct/incorrect styling) after selecting an answer.
*   **Score Tracking**: The application keeps a running tally of the user's correct answers.
*   **Result Summary**: A comprehensive summary is displayed at the end of the quiz, showing the final score and a personalized message.
*   **Restart Functionality**: Users can easily restart the quiz to try again.
*   **Responsive Design**: The layout adapts well to different screen sizes, from mobile devices to desktop computers.
*   **Single File Deployment**: All HTML, CSS, and JavaScript are bundled into a single `index.html` file, simplifying deployment.
*   **Professional Design**: Clean, modern, and user-friendly interface.
