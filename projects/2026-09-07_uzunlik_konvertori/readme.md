# uzunlik_konvertori (Length Converter)

## Loyiha nomi va tavsifi
**Uzunlik Konvertori** - Bu loyiha bitta HTML faylda joylashgan oddiy, ammo to'liq funksional uzunlik konvertoridir. Foydalanuvchilar kirish maydoniga qiymat kiritib, turli uzunlik birliklari (metr, kilometr, mil, fut, dyuym, santimetr, millimetr) o'rtasida real vaqt rejimida konvertatsiya qilishlari mumkin. Barcha CSS va JavaScript kodlari HTML fayl ichida (inline) yozilgan bo'lib, loyihaning ixchamligini ta'minlaydi.

## Qanday ishga tushirish mumkinligi
Loyiha juda sodda va hech qanday tashqi bog'liqliklarga ega emas. Uni ishga tushirish uchun quyidagi qadamlarni bajaring:

1.  `index.html` faylini saqlab oling.
2.  Saqlangan `index.html` faylini istalgan zamonaviy veb-brauzerda (Chrome, Firefox, Safari, Edge va hokazo) oching.
3.  Konvertor darhol ishga tushadi va foydalanishga tayyor bo'ladi.

## Xususiyatlar ro'yxati
*   **Real vaqt rejimida konvertatsiya:** Qiymat kiritishingiz yoki birlikni o'zgartirishingiz bilan natija darhol ko'rsatiladi.
*   **Ko'p birliklarni qo'llab-quvvatlash:** Metr, kilometr, mil, fut, dyuym, santimetr va millimetr kabi keng tarqalgan uzunlik birliklari mavjud.
*   **Toza va foydalanuvchi uchun qulay interfeys:** Zamonaviy va intuitiv dizayn foydalanishni osonlashtiradi.
*   **Bitta fayl arxitekturasi:** Barcha HTML, CSS va JavaScript kodlari bitta `index.html` faylida jamlangan.
*   **Tashqi bog'liqliklar yo'q:** Ishlash uchun hech qanday kutubxonalar, freymvorklar yoki internet aloqasi talab qilinmaydi.
*   **Javob beruvchan dizayn:** Kichikroq ekranlarda ham yaxshi ko'rinish uchun asosiy javob beruvchanlikka ega.
