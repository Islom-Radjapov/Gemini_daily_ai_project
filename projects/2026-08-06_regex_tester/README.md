# Python Regex Tester

## Project Name and Description
This is a simple, interactive command-line utility written in Python designed to help users test regular expressions (`regex`) against arbitrary text. It provides a straightforward way to see how different `re` module functions (`re.search()`, `re.findall()`, `re.sub()`) behave with a given regex pattern and input string. It's a handy tool for learning and debugging regex patterns.
