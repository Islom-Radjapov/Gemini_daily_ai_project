# simple_cli_encryption_program

## Project Name: Simple CLI Encryption Program

## Description
This is a basic command-line interface (CLI) application built with Python. It allows users to encrypt and decrypt text messages using the classic Caesar cipher method. The program is designed to be simple, interactive, and uses only Python's standard library modules, making it easy to run without any external dependencies.
