# Color Match Game

## Loyiha nomi va tavsifi

**Color Match Game** bu HTML5 Canvas yordamida yaratilgan oddiy va qiziqarli ranglarni moslashtirish o'yini. O'yinchining maqsadi – yuqorida ko'rsatilgan "MATCH THIS COLOR" yozuvli rangga mos keladigan variantni pastdagi to'rtta rang opsiyasidan topib bosish. O'yin vaqtga qarshi bo'lib, o'yinchilar berilgan vaqt ichida imkon qadar ko'proq to'g'ri javob topish orqali ball yig'ishlari kerak.

## Qanday ishga tushirish mumkinligi

Loyiha bitta HTML faylidan iborat bo'lib, uni ishga tushirish juda oddiy:

1.  `color_match_game.html` faylini kompyuteringizga yuklab oling.
2.  Faylni veb-brauzerda (masalan, Google Chrome, Firefox, Edge) oching. Buning uchun faylga ikki marta bosish yoki brauzerning "File" -> "Open File" menyusidan foydalanish kifoya.
3.  O'yin darhol brauzerda yuklanadi. O'yinni boshlash uchun "Start Game" tugmasini bosing.

Hech qanday server yoki qo'shimcha kutubxonalar talab qilinmaydi.

## Xususiyatlar ro'yxati

*   **HTML5 Canvas:** Barcha grafiklar va o'yin elementlari HTML5 Canvas API yordamida chiziladi.
*   **Intuitiv O'yin Jarayoni:** Yuqoridagi rangga mos keluvchi rangni pastdagi opsiyalardan tanlang.
*   **Vaqtga Qarshi O'yin:** Belinglanangan vaqt (standart bo'yicha 30 soniya) ichida maksimal ball yig'ishga harakat qiling.
*   **Ballni Hisoblash:** Har bir to'g'ri javob uchun ball beriladi.
*   **Visual Feedback:** To'g'ri yoki noto'g'ri tanlov uchun qisqa vizual xabarlar ko'rsatiladi.
*   **"Play Again" Funksiyasi:** O'yin tugaganidan so'ng qayta boshlash imkoniyati.
*   **Minimalist va Toza Dizayn:** Oddiy, ammo ko'zni quvontiradigan va tushunarli foydalanuvchi interfeysi.
*   **Bitta Faylda To'liq:** Barcha HTML, CSS va JavaScript kodlari bitta `color_match_game.html` faylida jamlangan bo'lib, loyihani tarqatish va ishga tushirishni osonlashtiradi.
*   **Standard Web Texnologiyalari:** Faqatgina HTML, CSS va JavaScript standart imkoniyatlaridan foydalanilgan.
