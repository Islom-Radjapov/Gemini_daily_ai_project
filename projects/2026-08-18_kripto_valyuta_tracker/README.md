# crypto_tracker_dashboard

## Project Name: Crypto Tracker Dashboard

## Description
This is a small, fully functional, and beautifully designed cryptocurrency tracker dashboard built entirely within a single HTML file. It uses inline CSS for styling and JavaScript for dynamic content, simulating real-time market data updates with fake information. The dashboard provides an overview of market statistics and a list of top cryptocurrencies with their prices, 24-hour changes, market caps, and volume, along with a simple trend visualization.

## How to Run
To run this project, simply follow these steps:
1.  Save the content of `crypto_tracker_dashboard.html` into a file named `crypto_tracker_dashboard.html` on your computer.
2.  Open the `crypto_tracker_dashboard.html` file using any modern web browser (e.g., Chrome, Firefox, Edge, Safari).

That's it! The dashboard will load and start displaying simulated data.

## Features
*   **Single File Project:** All HTML, CSS, and JavaScript are self-contained within one `crypto_tracker_dashboard.html` file.
*   **Modern & Dark Theme Design:** A sleek, professional dark theme with a clean user interface.
*   **Responsive Layout:** Adapts gracefully to various screen sizes, from desktop to mobile.
*   **Dynamic Data Simulation:** Displays fake cryptocurrency market data that updates every 5 seconds, giving the impression of live tracking.
*   **Overview Cards:** Shows key market metrics like Total Market Cap, 24h Volume, BTC Dominance, and ETH Gas Price.
*   **Market Trend Visualization:** A simple visual representation of overall market trends.
*   **Top Cryptocurrencies Table:** A detailed table listing top cryptocurrencies with their symbol, current price, 24-hour percentage change, market capitalization, 24-hour trading volume, and a mini-trend sparkline.
*   **Interactive Elements:** Hover effects on cards and table rows for enhanced user experience.
