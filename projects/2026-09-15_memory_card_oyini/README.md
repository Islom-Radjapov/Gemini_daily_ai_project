# canvas_memory_game

## Project Name
Canvas Memory Game

## Description
A classic memory card matching game implemented using HTML5 Canvas and pure JavaScript. The game challenges players to find matching pairs of cards by flipping them over. It tracks the number of moves taken to complete the game.

## How to Run
1. Save the `index.html` file to your computer.
2. Open the `index.html` file using any modern web browser (e.g., Chrome, Firefox, Safari, Edge).
3. The game will load automatically. Click on the cards to start playing!

## Features
*   **Interactive Gameplay**: Flip cards to find matching pairs.
*   **Canvas-based Rendering**: All game elements are drawn dynamically on an HTML5 Canvas.
*   **Score Tracking**: Keeps track of the number of moves (card flips) the player makes.
*   **Game Reset**: Automatically resets the game board upon completion or by clicking the "Play Again" area.
*   **Simple & Clean UI**: Minimalist design focused on gameplay.
*   **Responsive (Basic)**: Canvas size is fixed, but core logic handles card placement.
*   **Single File**: Entire game (HTML, CSS, JavaScript) is contained within one `index.html` file.
