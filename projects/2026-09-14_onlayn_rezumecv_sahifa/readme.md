# online_resume_cv_page

## Loyiha nomi: Onlayn Rezume/CV Sahifasi

## Tavsif
Ushbu loyiha — HTML, CSS va JavaScript yordamida yaratilgan toʻliq funksional, bir sahifali onlayn rezume (CV) sahifasidir. U toza, zamonaviy va sezgir dizaynga ega boʻlib, foydalanuvchi tajribasini oshirish uchun interaktiv "Dark/Light Mode" almashtirish tugmasini oʻz ichiga oladi. Barcha kodlar (HTML, CSS va JavaScript) bitta `index.html` faylida birlashtirilgan, bu uni juda qulay va portativ qiladi.

## Qanday ishga tushirish mumkin?
Loyiha faylini ishga tushirish juda oddiy:
1.  Yuqoridagi `index.html` faylini kompyuteringizga saqlang.
2.  Saqlangan `index.html` faylini istalgan zamonaviy veb-brauzerda (masalan, Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) oching.
3.  Sahifa avtomatik ravishda yuklanadi va siz Ali Valiyevning onlayn rezumesini ko'rishingiz mumkin.

## Xususiyatlar ro'yxati
*   **Toza va Zamonaviy Dizayn:** O'qishga qulay, professional va estetik jihatdan yoqimli UI.
*   **To'liq Javob beruvchi (Responsive):** Har xil ekran o'lchamlariga, jumladan mobil qurilmalarga avtomatik moslashadi.
*   **Interaktiv Dark/Light Mode:** Sahifaning yuqori o'ng burchagidagi tugma yordamida "Light" va "Dark" rejimlari o'rtasida osongina almashish mumkin. Tanlangan rejim brauzerning mahalliy xotirasida saqlanadi va sahifa qayta yuklanganda ham qo'llaniladi.
*   **Bitta Faylli Tuzilma:** Barcha HTML, CSS va JavaScript kodlari yagona `index.html` faylida joylashgan bo'lib, uni boshqarish va joylashtirishni juda soddalashtiradi.
*   **To'liq Kontent:** Rezume uchun zarur bo'lgan barcha bo'limlar (Shaxsiy ma'lumotlar, Men haqimda, Ish tajribasi, Ta'lim, Ko'nikmalar) to'liq to'ldirilgan.
*   **Professional Izohlar:** Kodni tushunishni osonlashtirish uchun ingliz tilida batafsil izohlar berilgan.
