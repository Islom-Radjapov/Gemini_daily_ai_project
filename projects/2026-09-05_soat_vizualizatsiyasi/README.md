# Digital Analog Clock Visualization

## Project Name: Digital Analog Clock Visualization

## Description:
This project is a simple yet elegant real-time clock visualization rendered using HTML Canvas. It displays both an analog clock with hour, minute, and second hands, as well as a digital time readout. The design is modern, clean, and fully functional, updating smoothly every frame. All CSS and JavaScript are embedded directly within a single HTML file for easy deployment and use.

## How to Run:
1.  **Save the file**: Copy the content of `digital_analog_clock_visualization.html` into a file named `digital_analog_clock_visualization.html`.
2.  **Open in browser**: Open the `digital_analog_clock_visualization.html` file with any modern web browser (e.g., Chrome, Firefox, Safari, Edge).
3.  **Enjoy**: The clock will immediately start displaying the current time.

## Features:
*   **Real-time Analog Clock**: Displays current time with smoothly moving hour, minute, and second hands.
*   **Digital Time Display**: Shows the current time in HH:MM:SS format below the analog clock.
*   **Modern & Clean Design**: Features a dark theme with contrasting colors, subtle shadows, and a professional look.
*   **Smooth Animation**: Uses `requestAnimationFrame` for fluid hand movements.
*   **Single File Deployment**: Entire project is self-contained within one HTML file, including all CSS and JavaScript.
*   **Customizable**: Easy to modify colors, sizes, and fonts by adjusting the inline CSS and JavaScript variables.
