# Neon Text Effect

## Loyiha nomi: Neon Matn Effekti

## Loyiha tavsifi
Ushbu loyiha CSS animatsiyalari yordamida yaratilgan, vizual jihatdan jozibali neon matn effektini namoyish etuvchi oddiy veb-sahifadir. Matn dinamik tarzda yonib-o'chib turadigan (flickering) va pulsatsiyalanuvchi (pulsating) jilo bilan bezatilgan bo'lib, o'ziga xos zamonaviy va professional ko'rinishga ega. Sahifa deyarli butunlay CSS bilan qurilgan bo'lib, minimal JavaScript faqat yuklash jarayonini bildirish uchun ishlatiladi.

## Qanday ishga tushirish mumkin?
1.  **Faylni saqlash:** `index.html` faylini kompyuteringizda istalgan joyga saqlang.
2.  **Brauzerda ochish:** Saqlangan `index.html` faylini ikki marta bosing yoki veb-brauzeringizda ochish orqali ko'ring (Chrome, Firefox, Safari, Edge va h.k.).
3.  **Natija:** Siz qora fonda yonib-o'chib turuvchi neon matn effektini ko'rasiz.

## Xususiyatlar ro'yxati
*   **Sof CSS Neon Effekti:** Matnning asosiy neon jilosi va animatsiyalari butunlay CSS yordamida yaratilgan.
*   **Vibratsiyali Jilo:** Ko'p qatlamli `text-shadow` yordamida chuqur va boy neon jilosi hosil qilingan.
*   **Yonib-o'chish Animatsiyasi:** Realistik yonib-o'chish effektini beruvchi `@keyframes` animatsiyasi.
*   **Zamonaviy Dizayn:** Qora fon va oqlangan shrift matnning ko'rinishini kuchaytiradi.
*   **Minimal JavaScript:** Sahifa yuklanganligini bildiruvchi juda kichik JavaScript kodi (konsolda xabar chiqariladi).
*   **Responzivlik:** Asosiy matn markazlashtirilgan bo'lib, turli ekran o'lchamlarida yaxshi ko'rinadi (asosiy e'tibor matn effektiga qaratilgan).
