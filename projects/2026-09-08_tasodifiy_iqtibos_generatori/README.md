# tasodifiy_iqtibos_generator

## Loyiha nomi
Tasodifiy Iqtibos Generator (Random Quote Generator)

## Tavsif
Bu loyiha terminal/konsolda ishlaydigan oddiy Python dasturidir. U foydalanuvchiga tasodifiy iqtiboslarni ko'rsatadi. Dastur butunlay standart Python kutubxonalari yordamida yozilgan bo'lib, tashqi bog'liqliklarga ega emas.
