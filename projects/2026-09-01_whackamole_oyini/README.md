# Whack-a-Mole Game

## Project Description
This is a classic arcade-style Whack-a-Mole game implemented entirely within a single HTML file using HTML5 Canvas and JavaScript. Players test their reflexes by clicking on moles as they randomly pop up from their holes before they disappear. The goal is to hit as many moles as possible within a given time limit to achieve the highest score.

## How to Run
1.  **Save the file:** Copy all the content provided for `whack_a_mole.html` into a new text file.
2.  **Name the file:** Save the text file as `whack_a_mole.html`.
3.  **Open in browser:** Open the `whack_a_mole.html` file using any modern web browser (e.g., Chrome, Firefox, Edge, Safari).
4.  **Start playing:** Click the "Start Game" button to begin the game.

## Features
*   **Canvas-based graphics:** All game elements (moles, holes, background) are drawn dynamically on an HTML5 Canvas.
*   **Interactive gameplay:** Players click on moles to score points.
*   **Dynamic mole spawning:** Moles appear and disappear randomly across predefined holes.
*   **Score tracking:** Keeps track of the player's score.
*   **Countdown timer:** A 30-second timer limits the game duration.
*   **Game Over screen:** Displays the final score and offers a "Play Again" option.
*   **Basic sound feedback:** Distinct sounds for hitting a mole and missing one (clicking empty space).
*   **Responsive design (basic):** The canvas and UI elements are centered and adapt somewhat to screen size.
*   **Single-file implementation:** All HTML, CSS, and JavaScript are contained within `whack_a_mole.html` for easy deployment and sharing.
*   **Clean and modern UI:** A simple, visually appealing design.
