# Finance Dashboard

## Project Name and Description
This project is a simple, modern, and fully functional **Finance Dashboard**. It's designed to provide a quick overview of personal financial health, including total balance, monthly income, expenses, savings progress, recent transactions, and a simplified investment portfolio. The dashboard is presented in a single HTML file, leveraging inline CSS for styling and inline JavaScript for data management and dynamic content updates. All data displayed is simulated (fake data).

## How to Run
Since this is a single HTML file project, running it is extremely straightforward:

1.  **Save the file:** Save the content of `index.html` into a file named `index.html` on your computer.
2.  **Open in Browser:** Double-click the `index.html` file, or drag and drop it into any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

That's it! The dashboard will load directly in your browser. No server, no complex setup required.

## Features
*   **Single File Simplicity:** Entire project contained within one `index.html` file (HTML, CSS, JavaScript).
*   **Modern & Clean Design:** A professional and aesthetically pleasing user interface with a clear layout.
*   **Dynamic Data Display:** JavaScript populates key financial metrics such as:
    *   Total Balance
    *   Monthly Income
    *   Monthly Expenses
    *   Savings Progress (with a visual progress bar)
*   **Recent Transactions:** A table displaying a list of recent income and expense transactions.
*   **Investment Overview:** A simple section showing a mock investment portfolio with current values and performance.
*   **User-friendly Interface:** Intuitive layout making it easy to digest financial information at a glance.
*   **Responsive Layout:** Basic responsiveness ensures the dashboard looks decent on various screen sizes.
*   **Fake Data:** Uses predefined JavaScript objects for all financial data, making it easy to understand and modify the data structure.
