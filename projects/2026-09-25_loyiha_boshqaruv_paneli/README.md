# project_management_dashboard

## Loyiha nomi va tavsifi
**Loyiha boshqaruv paneli** — bu loyihalar va vazifalar holatini kuzatish uchun mo'ljallangan kichik, ammo to'liq ishlaydigan va vizual jozibali veb-dashboard. U bitta HTML faylida yaratilgan bo'lib, zamonaviy CSS dizayni va dinamik kontentni ko'rsatish uchun JavaScript-dan foydalanadi (soxta ma'lumotlar bilan). Asosiy maqsad – loyiha menejerlari yoki jamoa a'zolari uchun loyihaning umumiy ahvoli, faol vazifalar, muddati o'tgan ishlar va so'nggi harakatlar haqida tezkor ma'lumot berish.

## Qanday ishga tushirish mumkinligi
Bu loyiha juda sodda tuzilishga ega va hech qanday maxsus server yoki kutubxonalarni talab qilmaydi.
Ishga tushirish uchun quyidagi qadamlarni bajaring:

1.  `index.html` faylini kompyuteringizga yuklab oling.
2.  Faylni veb-brauzeringizda (Chrome, Firefox, Edge, Safari va boshqalar) oching. Buning uchun faylni ikki marta bosish kifoya, yoki brauzeringizni ochib, "File" (Fayl) -> "Open File..." (Faylni ochish...) menyusidan foydalanishingiz mumkin.

Va tamom! Dashboard darhol brauzeringizda ochiladi va ishlashni boshlaydi.

## Xususiyatlar ro'yxati
*   **Yagona fayl arxitekturasi:** Barcha HTML, CSS va JavaScript kodlari bitta `index.html` faylida jamlangan.
*   **Zamonaviy dizayn:** Toza, professional va mobil qurilmalarga moslashuvchan (responsive) dizayn.
*   **Loyiha statistikasi:** Umumiy loyihalar, faol loyihalar, yakunlangan vazifalar va muddati o'tgan vazifalar kabi asosiy ko'rsatkichlarni tezkor ko'rish.
*   **Loyiha ro'yxati:** Loyihalar nomi, holati, rivojlanish foizi va muddati bilan jadval ko'rinishida.
*   **Vazifa holati diagrammasi (soddalashtirilgan):** Vazifalarning turli holatlardagi taqsimotini ko'rsatuvchi progress barlar.
*   **So'nggi faoliyatlar lentasi:** Loyihalar bo'yicha eng so'nggi yangilanishlar va harakatlar.
*   **Dinamik kontent:** JavaScript yordamida soxta ma'lumotlar avtomatik tarzda yuklanadi va ko'rsatiladi.
*   **Interaktiv navigatsiya:** Yon paneldagi navigatsiya elementlari hover effektlariga ega.
*   **Ingliz tilidagi izohlar:** Kodni tushunishni osonlashtirish uchun barcha kod izohlari ingliz tilida yozilgan.
