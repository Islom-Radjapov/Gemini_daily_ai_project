# hayvonlar_viktorinasi

## Loyiha nomi: Hayvonlar Viktorinasi

## Tavsif
Bu loyiha interaktiv veb-asoslangan viktorina (quiz) ilovasi bo'lib, hayvonlar haqidagi bilimlarni sinashga qaratilgan. Foydalanuvchilar bir nechta variantli savollarga javob berishlari va oxirida o'z ballarini ko'rishlari mumkin. Dastur HTML, CSS va JavaScript yordamida bitta faylda yaratilgan bo'lib, hech qanday qo'shimcha kutubxonalar yoki server talab qilmaydi.

## Qanday ishga tushirish mumkin
1.  **`animal_quiz.html`** faylini yaratish va yuqorida keltirilgan kodni unga joylashtirish.
2.  Yaratilgan **`animal_quiz.html`** faylini istalgan veb-brauzerda (Chrome, Firefox, Edge va hokazo) oching.
3.  Viktorina avtomatik ravishda boshlanadi.

## Xususiyatlar ro'yxati
*   **Interaktiv savollar**: Hayvonlar haqida 12 ta ko'p tanlovli savol.
*   **Ballarni hisoblash**: Foydalanuvchining to'g'ri javoblari soni hisoblab boriladi.
*   **Natijani ko'rsatish**: Viktorina yakunida umumiy ball ko'rsatiladi.
*   **Qayta boshlash imkoniyati**: Foydalanuvchi viktorinani istalgan vaqtda qayta boshlashi mumkin.
*   **Zamonaviy dizayn**: Toza, ko'rkam va mobil qurilmalarga mos keladigan (responsive) interfeys.
*   **Yagona fayl**: Barcha HTML, CSS va JavaScript kodlari bitta `animal_quiz.html` faylida joylashgan bo'lib, uni ishga tushirish juda oson.
