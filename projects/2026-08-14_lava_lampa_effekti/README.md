# interactive_lava_lamp_effect

## Project Name: Interactive Lava Lamp

## Description
This project creates a mesmerizing interactive lava lamp effect right in your web browser. It leverages HTML5 Canvas, CSS, and JavaScript to simulate fluid, colorful blobs that dynamically merge, split, and move across the screen. The "metaball" like effect is achieved using CSS filters on the canvas context, providing a smooth, organic feel.

Users can interact with the lava lamp in real-time:
*   **Mouse Interaction:** Moving the mouse cursor will attract the blobs, allowing you to influence their movement and formation.
*   **Keyboard Interaction:** Pressing the `Spacebar` key will introduce a new, randomly generated lava blob into the simulation, adding more dynamism to the display.

The design is clean, modern, and responsive, adapting seamlessly to different window sizes. It's a small but complete piece of interactive art, perfect for relaxation or as a playful visual experience.

## Qanday ishga tushirish mumkinligi (How to Run)

Loyiha bitta HTML faylidan iborat bo'lib, uni ishga tushirish juda oddiy:

1.  **Faylni saqlash:** Yuqorida berilgan HTML kodini `interactive_lava_lamp_effect.html` nomi bilan kompyuteringizga saqlang.
2.  **Brauzerda ochish:** Saqlangan `interactive_lava_lamp_effect.html` faylini istalgan zamonaviy veb-brauzer (masalan, Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) orqali oching. Shunchaki faylga ikki marta bosing yoki brauzerga tortib tashlang.
3.  **Huzur qiling:** Lava lampa effekti avtomatik ravishda ishga tushadi. Sichqoncha harakatlari va `SPACEBAR` tugmasi yordamida u bilan o'zaro aloqada bo'lishingiz mumkin.

## Xususiyatlar ro'yxati (Features List)

*   **Dinamik lava lampa simulyatsiyasi:** HTML5 Canvas yordamida suyuq, metaballga o'xshash effektdagi harakatlanuvchi rangli sharlarni taqdim etadi.
*   **Sichqoncha bilan o'zaro aloqa:** Bloblar sichqoncha kursori joylashgan nuqtaga tortiladi, bu sizga ularning harakatini nazorat qilish imkonini beradi.
*   **Klaviatura bilan o'zaro aloqa:** `SPACEBAR` tugmasini bosish har safar yangi, tasodifiy yaratilgan lava blobini qo'shadi.
*   **Devor to'qnashuvlari:** Bloblar ekran chegaralariga yetganda, organik ravishda orqaga qaytadi.
*   **Moslashuvchan dizayn:** Canvas to'liq oynani egallaydi va oynaning hajmi o'zgarganda avtomatik ravishda moslashadi.
*   **Chiroyli ranglar:** Jonli HSL ranglar palitrasidan foydalanilgan bo'lib, tasodifiy ranglarga ega bo'lgan bloblar yaratiladi.
*   **Bitta faylli yechim:** Barcha HTML, CSS va JavaScript kodlari bitta `interactive_lava_lamp_effect.html` faylida inline tarzda joylashtirilgan.
*   **Zamonaviy estetik:** Toza va professional vizual ko'rinishga ega.
*   **Foydalanuvchi ko'rsatmalari:** Boshlang'ich qadamda interaktiv qo'llanma ko'rsatiladi, keyin esa yashirinadi.
