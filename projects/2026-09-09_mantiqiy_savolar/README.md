# Mantiqiy Viktorina

## Loyiha Nomi
Mantiqiy Viktorina

## Loyiha Tavsifi
"Mantiqiy Viktorina" - bu interaktiv veb-asosidagi test dasturi bo'lib, unda foydalanuvchilar mantiqiy savollarga javob berish orqali o'z bilimlarini sinab ko'rishlari mumkin. Dastur HTML, CSS va JavaScript yordamida bitta sahifada yaratilgan bo'lib, foydalanish uchun qulay va zamonaviy dizaynga ega.

## Qanday Ishga Tushirish Mumkin
1.  Yuqoridagi kodni `index.html` nomli faylga saqlang.
2.  `index.html` faylini istalgan zamonaviy veb-brauzerda (Chrome, Firefox, Edge, Safari va boshqalar) oching.
3.  Viktorina avtomatik ravishda ishga tushadi va siz "Viktorinani Boshlash" tugmasini bosib savollarga javob berishni boshlashingiz mumkin.

## Xususiyatlar Ro'yxati
*   **Interaktiv Savollar:** Foydalanuvchilar har bir savol uchun bir nechta javob variantlaridan birini tanlashlari mumkin.
*   **Kamida 10 ta Savol:** Loyihada 10 ta mantiqiy savol mavjud.
*   **Tezkor Fikr-mulohaza:** Har bir javobdan so'ng, foydalanuvchi javobining to'g'ri yoki noto'g'riligi haqida darhol xabar oladi.
*   **Javob Tushuntirishi:** Har bir javobdan keyin, to'g'ri javobning tushuntirishi ko'rsatiladi.
*   **Hisobni Yuritish:** Foydalanuvchining umumiy to'g'ri javoblari soni hisoblab boriladi.
*   **Natijalar Ekrani:** Viktorina yakunida umumiy ball va natijalar ko'rsatiladi.
*   **Qayta Boshlash Imkoniyati:** Foydalanuvchilar viktorinani istalgan vaqtda qayta boshlashlari mumkin.
*   **Yagona Fayl:** Barcha HTML, CSS va JavaScript kodlari bitta `index.html` faylida birlashtirilgan.
*   **Toza va Zamonaviy Dizayn:** CSS yordamida foydalanuvchi uchun yoqimli va tushunarli interfeys yaratilgan.
*   **Adaptiv Dizayn:** Mobil va kompyuter ekranlariga moslashgan ko'rinishga ega.
