# Interactive Treemap Visualization

## Project Name
Interactive Treemap Visualization (HTML Canvas/SVG)

## Project Description
This project delivers a small, self-contained, and fully functional interactive Treemap visualization within a single HTML file. It uses SVG (Scalable Vector Graphics) to render hierarchical data as a set of nested rectangles, where the size of each rectangle is proportional to its corresponding data value. The visualization includes a custom tooltip that displays detailed information on hover.

The Treemap employs a "slice-and-dice" layout algorithm, alternating between horizontal and vertical divisions at each level of the hierarchy. This approach, while simpler than squarified treemaps, effectively demonstrates the core principles of treemap visualization and is easy to implement from scratch.

## How to Run
1.  **Save the file:** Save the entire content of `treemap_visualization.html` into a file named `treemap_visualization.html` on your computer.
2.  **Open in browser:** Double-click the `treemap_visualization.html` file, or open it directly with any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

The visualization will load instantly in your browser. No server or additional setup is required.

## Features
*   **Single File Solution:** All HTML, CSS, and JavaScript are contained within a single `treemap_visualization.html` file.
*   **SVG-based Visualization:** Utilizes SVG for scalable and crisp graphics, ensuring high quality regardless of zoom level.
*   **Hierarchical Data Support:** Visualizes nested data structures, allowing users to understand proportions at different levels.
*   **Slice-and-Dice Layout:** Implements a fundamental treemap layout algorithm for clear hierarchical representation.
*   **Interactive Tooltip:** Displays contextual information (name and value) for each rectangle when hovered over.
*   **Dynamic Sizing:** Rectangles are sized proportionally to their data values.
*   **Clear Labeling:** Node names are displayed directly on the rectangles, with dynamic sizing to prevent overlap on smaller areas.
*   **Professional Design:** Clean, modern aesthetic with a harmonious color palette and smooth transitions on hover.
*   **Browser Compatibility:** Works in all modern web browsers without external dependencies.
*   **Well-commented Code:** English comments explain complex parts of the JavaScript code.
