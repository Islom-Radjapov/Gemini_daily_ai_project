# javlonbek_portfolio_website

## Loyiha nomi: Javlonbek's Portfolio Website

## Tavsif
Bu loyiha HTML, CSS va JavaScript yordamida yaratilgan, bitta faylli, to'liq ishlaydigan va interaktiv shaxsiy portfolio veb-sahifasidir. Sahifa zamonaviy va professional ko'rinishga ega bo'lib, quyidagi bo'limlarni o'z ichiga oladi: Bosh sahifa (Hero), Men haqimda (About), Ko'nikmalar (Skills), Loyihalar (Projects) va Aloqa (Contact). Barcha stil va skriptlar `index.html` faylining ichida (inline) joylashgan bo'lib, uni ishga tushirish juda oson.

## Qanday ishga tushirish mumkin
Loyiha faqat bitta `index.html` faylidan iborat bo'lgani sababli, uni ishga tushirish juda oddiy:
1.  Yuqoridagi `index.html` faylining tarkibini kompyuteringizda yangi `.html` kengaytmali faylga saqlang (masalan, `index.html`).
2.  Saqlangan `index.html` faylini veb-brauzeringizda (Chrome, Firefox, Edge va hokazo) oching. Faylni ikki marta bosish orqali ham ochishingiz mumkin.
3.  Sahifa darhol yuklanadi va siz uning funksionalligini ko'rishingiz mumkin.

## Xususiyatlar ro'yxati
*   **Bitta fayl arxitekturasi:** Barcha HTML, CSS va JavaScript bitta `index.html` faylida.
*   **To'liq ishlaydigan:** Hech qanday TODO yoki placeholder qoldiqlarisiz, to'liq mazmun bilan.
*   **Interaktiv navigatsiya:** Navigatsiya havolalarini bosganda sahifaning tegishli bo'limlariga silliq o'tish (smooth scroll) animatsiyasi.
*   **Zamonaviy dizayn:** Toza, minimalist va mobil qurilmalarga mos (responsive) dizayn.
*   **Alohida bo'limlar:**
    *   **Hero Section:** Shaxsiy ism, kasb va harakatga undovchi tugma.
    *   **About Section:** Kichik biografi va ko'nikmalarni rivojlantirishga urg'u.
    *   **Skills Section:** Ko'nikmalar ro'yxati (HTML, CSS, JS, React, Node.js, Git).
    *   **Projects Section:** Namuna loyihalar kartalari, har birida nom, tavsif va havola.
    *   **Contact Section:** Aloqa ma'lumotlari va elektron pochta manzili.
*   **Professional kod:** Semantik HTML, yaxshi tuzilgan CSS va tushunarli JavaScript.
*   **Ingliz tilidagi izohlar:** Kodni tushunishni osonlashtirish uchun ingliz tilida izohlar.
