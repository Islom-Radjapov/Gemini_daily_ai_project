# Sport Viktorinasi

## Loyiha nomi va tavsifi
**Sport Viktorinasi** - bu HTML, CSS va JavaScript yordamida yaratilgan interaktiv sport viktorinasi dasturi. U foydalanuvchilarni turli sport turlari bo'yicha 10 ta ko'p tanlovli savollar bilan sinovdan o'tkazadi, tezkor javob qaytarish imkoniyatini beradi va yakuniy natijani ko'rsatadi.

## Qanday ishga tushirish mumkinligi
Loyiha faqat bitta fayldan iborat. Uni ishga tushirish uchun quyidagi oddiy qadamlarni bajaring:
1.  `index.html` faylini kompyuteringizga yuklab oling.
2.  Faylni ikki marta bosing yoki istalgan zamonaviy veb-brauzer (masalan, Google Chrome, Mozilla Firefox, Microsoft Edge) orqali oching.

Dastur brauzerda avtomatik ravishda ishga tushadi.

## Xususiyatlar ro'yxati
*   **10 ta ko'p tanlovli sport savollari:** Sport olami bo'yicha bilimingizni sinash uchun tanlangan savollar.
*   **Interaktiv foydalanuvchi interfeysi:** Foydalanuvchi qulayligi uchun intuitiv va tushunarli dizayn.
*   **Har bir javob uchun tezkor fikr-mulohaza:** Javob berishingiz bilanoq to'g'ri yoki noto'g'ri ekanligi haqida ma'lumot olasiz.
*   **Ballarni hisoblash:** To'g'ri javoblar asosida umumiy ballaringizni kuzatib boradi.
*   **Yakuniy natijalarni ko'rsatish:** Viktorina tugaganidan so'ng umumiy ballingizni namoyish etadi.
*   **Viktorinani qayta boshlash funksiyasi:** Istalgan vaqtda viktorinani boshidan boshlashingiz mumkin.
*   **To'liq bitta faylda:** HTML, CSS va JavaScript bitta `index.html` faylida birlashtirilgan bo'lib, loyihani tarqatish va ishga tushirishni osonlashtiradi.
*   **Professional va zamonaviy dizayn:** Foydalanuvchi tajribasini oshirish uchun estetik jihatdan yoqimli va funksional dizayn.
