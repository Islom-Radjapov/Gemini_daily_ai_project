# analytics_dashboard

## Loyiha nomi: Analitika Dashboard

## Tavsif
Ushbu loyiha bitta HTML fayl ichida yaratilgan sodda, ammo to'liq ishlaydigan analitika dashboardidir. U asosiy ko'rsatkichlarni va ma'lumotlarni vizuallashtirishni zamonaviy va toza foydalanuvchi interfeysi orqali ko'rsatadi. Barcha ma'lumotlar soxta tarzda yaratilgan va JavaScript yordamida dinamik ravishda yangilanadi.

## Qanday ishga tushirish mumkin?
Loyiha juda sodda tuzilgan. Uni ishga tushirish uchun quyidagi qadamlarni bajaring:
1. `analytics_dashboard.html` faylini kompyuteringizga yuklab oling.
2. Faylni sevimli veb-brauzeringizda (masalan, Google Chrome, Mozilla Firefox, Microsoft Edge) oching. Shunchaki faylga ikki marta bosing yoki brauzerning "Fayl > Ochish" menyusidan foydalaning.
3. Dashboard darhol yuklanadi va soxta ma'lumotlarni ko'rsatadi.

Hech qanday server sozlamalari yoki qo'shimcha kutubxonalar o'rnatish talab qilinmaydi.

## Xususiyatlar ro'yxati
*   **Yagona HTML fayl:** Butun loyiha (HTML, CSS va JavaScript) bitta faylda joylashgan bo'lib, bu uni juda portativ va ishga tushirishni osonlashtiradi.
*   **Toza va zamonaviy UI dizayni:** Material dizayn tamoyillariga asoslangan, o'qishga qulay shriftlar, ranglar va soya effektlari bilan professional ko'rinishga ega.
*   **Asosiy yig'ma ko'rsatkichlar:** Umumiy foydalanuvchilar, daromad, sahifa ko'rishlari va sakrash darajasi kabi muhim metrikalar aniq kartochkalar shaklida ko'rsatiladi.
*   **CSS-da vizuallashtirilgan diagrammalar:** Sotish tendensiyalari va trafik manbalari kabi ma'lumotlar toza va interaktiv bo'lmagan, lekin estetik jihatdan yoqimli CSS-da yaratilgan grafikalar orqali tasvirlangan.
*   **Dinamik sanasi va vaqti:** Dashboard sarlavhasida joriy sana va vaqt dinamik ravishda ko'rsatiladi va har soniyada yangilanadi.
*   **Soxta ma'lumotlar:** Barcha ma'lumotlar (statistikalar, grafiklar va so'nggi harakatlar) JavaScript tomonidan avtomatik ravishda yaratiladi va har safar sahifa yuklanganda yangilanadi.
*   **Adaptiv dizayn (eng asosiy darajada):** Kontent ko'rsatish tartibi ma'lum darajada o'zgaradi, lekin u asosan ish stoli ekranlari uchun optimallashtirilgan.
