# Python Port Scanner

A lightweight and efficient utility written in Python for scanning open TCP ports on a target host. This tool is designed to be straightforward, fast, and uses only Python's standard libraries, making it highly portable.

## Loyiha Tavsifi (Project Description)

This project provides a command-line utility for scanning network ports. It allows users to specify a target host (IP address or hostname) and a range of ports to scan. The scanner utilizes multi-threading to speed up the process by concurrently attempting connections to multiple ports. It's an excellent example of how Python can be used for network utilities and includes robust error handling and clear output.
