# url_shortener_project

## Loyiha nomi va tavsifi

**Loyiha nomi:** Python URL qisqartiruvchi yordamchi dastur (Python URL Shortener Utility)

**Tavsif:** Bu loyiha Python dasturlash tilida yozilgan oddiy buyruq qatori URL qisqartirish yordamchi dasturidir. U uzoq URL manzillarni qisqa, eslab qolish oson kodlarga aylantirish va ushbu qisqa kodlarni asl URLlarga qayta yo'naltirish imkoniyatini beradi. Barcha URL xaritalari `urls.json` faylida saqlanadi, bu esa loyihaning barcha faoliyatlari uchun doimiylikni ta'minlaydi. Loyiha faqat Python standart kutubxonalaridan foydalanadi, qo'shimcha bog'liqliklarni talab qilmaydi, shu sababli o'rnatish va ishlatish juda oson.
