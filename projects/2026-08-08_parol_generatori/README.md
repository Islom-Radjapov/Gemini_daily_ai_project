# python_cli_password_generator

## Project Name
Python CLI Password Generator

## Description
The `python_cli_password_generator` is a simple yet robust command-line interface (CLI) tool designed to generate strong and secure random passwords. It allows users to customize the password length and specify which character types (lowercase, uppercase, digits, special characters) should be included. Built entirely with standard Python libraries, it's a lightweight and portable solution for your password generation needs.

## How to Run
To run this password generator, you need Python 3 installed on your system.

1.  **Save the script**: Download or copy the `password_generator.py` file into a directory on your computer.

2.  **Open your terminal or command prompt**: Navigate to the directory where you saved `password_generator.py`.
