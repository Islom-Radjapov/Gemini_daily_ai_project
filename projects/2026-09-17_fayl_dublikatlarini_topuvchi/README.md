# Python File Duplicate Finder

## Project Name
**Python File Duplicate Finder Utility**

## Project Description
This is a lightweight and efficient command-line utility written entirely in Python, designed to identify duplicate files within a specified directory and its subdirectories. It achieves this by calculating cryptographic hashes (MD5 by default) of file contents, ensuring accurate detection of identical files regardless of their names or modification dates. This tool is perfect for cleaning up disk space or organizing cluttered directories.

## How to Run
To run this utility, you need Python 3 installed on your system.

1.  **Save the script:** Save the provided `duplicate_finder.py` file to your local machine.
2.  **Open your terminal or command prompt.**
3.  **Navigate to the directory** where you saved the script (optional, you can also use the full path to the script).
4.  **Execute the script** by providing the path to the directory you want to scan for duplicates as a command-line argument.
