# Age Calculator

This is a simple, beautiful, and fully functional Age Calculator web application. It allows users to input their birthdate and instantly calculates their current age in years, months, and days. The entire application is contained within a single HTML file, utilizing inline CSS for styling and inline JavaScript for its interactive logic.

## How to Run

1.  **Save the file:** Save the provided `age_calculator.html` content into a file named `age_calculator.html` on your computer.
2.  **Open in browser:** Double-click the `age_calculator.html` file, or drag and drop it into any modern web browser (like Chrome, Firefox, Edge, Safari).

## Features

*   **Birthdate Input:** Easy-to-use date picker for selecting the birthdate.
*   **Accurate Age Calculation:** Calculates age in years, months, and days based on the current date.
*   **Dynamic Display:** Instantly updates the age result upon calculation.
*   **Single File:** All HTML, CSS, and JavaScript are bundled into one file for simplicity and portability.
*   **Modern Design:** Clean, intuitive, and aesthetically pleasing user interface with responsive adjustments.
*   **Input Validation:** Prevents selecting future dates and prompts the user if no date is selected.
*   **Default Date:** Pre-fills with a reasonable default date (e.g., 25 years ago) and calculates on load to demonstrate functionality.
