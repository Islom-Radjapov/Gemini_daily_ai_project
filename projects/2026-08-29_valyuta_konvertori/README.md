# Simple CLI Currency Converter

## Project Name and Description
This is a `Simple CLI Currency Converter`, a command-line interface (CLI) application written in Python. It allows users to convert a specified amount from one currency to another directly within the terminal. The application focuses on ease of use, clear prompts, and provides immediate conversion results.

**Important Note:** To adhere strictly to the "standard libraries only" rule, this converter uses a set of **hardcoded, static exchange rates**. This means the rates are not updated in real-time and are fixed as of the development time. For real-time rates, external APIs and libraries like `requests` would be necessary, which are outside the scope of this project's constraints.
