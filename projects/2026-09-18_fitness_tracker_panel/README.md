# Fitness Tracker Panel

## Loyiha nomi va tavsifi
**Fitness Tracker Panel** — bu zamonaviy va sezgir veb-dashboard bo'lib, u fitness ma'lumotlarini kuzatish uchun mo'ljallangan. U asosiy ko'rsatkichlarni, faoliyat tendentsiyalarini va yaqindagi mashg'ulotlarni toza dizayn va soxta ma'lumotlar yordamida namoyish etadi. Maqsad foydalanuvchiga uning jismoniy faoliyati haqida vizual va tushunarli ma'lumotlarni taqdim etishdir. Loyiha faqat bitta HTML faylida, barcha CSS va JavaScript kodlari uning ichida joylashgan holda yaratilgan.

## Qanday ishga tushirish mumkin
Loyiha bitta HTML faylidan iborat bo'lganligi sababli, uni ishga tushirish juda oddiy:
1.  `fitness_tracker_panel.html` faylini yuklab oling.
2.  Faylni veb-brauzeringizda (masalan, Chrome, Firefox, Edge) oching. Buning uchun faylni ikki marta bosish yoki brauzerga sudrab olib borish kifoya.

Hech qanday server yoki qo'shimcha konfiguratsiya talab qilinmaydi.

## Xususiyatlar ro'yxati
*   **Asosiy ko'rsatkichlarga umumiy nazar:** Umumiy qadamlar, yoqilgan kaloriyalar, faol daqiqalar va uyqu soatlari kabi asosiy fitness ko'rsatkichlarini tezkor ko'rib chiqish.
*   **Kunlik qadamlar tendentsiyasi diagrammasi:** So'nggi 7 kun ichidagi qadamlar sonining o'zgarishini ko'rsatuvchi interaktiv chiziqli diagramma.
*   **Faoliyat turlari bo'yicha taqsimot diagrammasi:** Turli xil mashg'ulot turlari (yugurish, yurish, velosipedda yurish, kuch mashqlari) umumiy faoliyatga qanday hissa qo'shishini ko'rsatuvchi dumaloq diagramma.
*   **So'nggi faoliyatlar ro'yxati:** Oxirgi mashg'ulotlar haqida batafsil ma'lumot (sana, turi, davomiyligi, yoqilgan kaloriyalar).
*   **Toza va zamonaviy dizayn:** Foydalanuvchi uchun qulay va vizual jozibador interfeys.
*   **Sezgir dizayn:** Turli xil ekran o'lchamlarida (ish stoli, planshet) yaxshi ko'rinish va ishlash qobiliyati.
*   **Bitta HTML fayli:** Barcha frontend kodlari (HTML, CSS, JavaScript) bitta faylda birlashtirilgan, bu uni osongina tarqatish va ishlatish imkonini beradi.
*   **Soxta ma'lumotlar:** Haqiqiy ma'lumotlarga ehtiyoj sezmasdan loyihaning funksionalligini namoyish etish uchun dinamik ravishda soxta ma'lumotlar yaratiladi.
