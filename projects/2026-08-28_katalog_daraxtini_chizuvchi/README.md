# Directory Tree CLI

## Project Name
Directory Tree CLI

## Project Description
The Directory Tree CLI is a simple yet powerful Python command-line utility designed to visualize the directory structure of a specified path in a hierarchical, tree-like format. It's built using only standard Python libraries, making it lightweight and easy to run on any system with Python installed.
