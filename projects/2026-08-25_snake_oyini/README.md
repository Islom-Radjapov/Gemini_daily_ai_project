# Snake Game

## Project Name
Snake Game

## Description
This is a classic Snake game implemented entirely in a single HTML file using HTML5 Canvas, JavaScript, and inline CSS. The goal is to control a snake to eat food, grow longer, and avoid hitting the walls or its own body.

## How to Run
1. Save the `index.html` file to your computer.
2. Open the `index.html` file with any modern web browser (e.g., Chrome, Firefox, Safari, Edge).
3. The game will start automatically. Use the arrow keys to control the snake.

## Features
*   **Classic Gameplay:** Enjoy the traditional Snake game mechanics.
*   **HTML5 Canvas:** Smooth rendering of game elements.
*   **Keyboard Controls:** Use arrow keys (Up, Down, Left, Right) to navigate the snake.
*   **Score Tracking:** Keep track of your current score.
*   **High Score:** Your highest score is saved locally in your browser's storage.
*   **Game Over Detection:** The game ends if the snake hits a wall or itself.
*   **Restart Functionality:** Easily restart the game after a game over.
*   **Single File:** All HTML, CSS, and JavaScript are contained within `index.html` for easy deployment and sharing.
*   **Responsive Design:** Basic responsiveness to center the game.
