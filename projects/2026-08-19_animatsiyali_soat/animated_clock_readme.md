# Animated CSS Clock

## Loyiha nomi: Animated CSS Clock

## Tavsif:
Ushbu loyiha CSS animatsiyalari yordamida yaratilgan, real vaqtda ishlaydigan, zamonaviy va minimalist dizayndagi animatsiyali soatdir. Loyiha faqat bitta HTML faylidan iborat bo'lib, barcha stil va skriptlar uning ichida joylashgan. JavaScript minimal darajada ishlatilgan bo'lib, uning vazifasi faqat hozirgi vaqtni olish va soat strelkalarining holatini CSS o'zgaruvchilari orqali yangilashdan iborat. Strelkalarning silliq harakati va estetik ko'rinishi CSS `transition` xususiyati orqali ta'minlanadi.

## Qanday ishga tushirish mumkinligi:
1. `animated_clock_index.html` faylini saqlang.
2. Faylni istalgan zamonaviy veb-brauzerda oching (masalan, Chrome, Firefox, Safari).
3. Soat sahifada darhol paydo bo'ladi va real vaqtni ko'rsata boshlaydi.

## Xususiyatlar ro'yxati:
*   **Real vaqtda ishlash:** Soat sizning kompyuteringizning hozirgi vaqtini aniq aks ettiradi.
*   **Minimalist dizayn:** Toza va zamonaviy ko'rinishga ega.
*   **CSS-ga asoslangan animatsiya:** Strelkalarning harakati JavaScript emas, balki CSS `transition` xususiyati yordamida silliq animatsiya qilinadi.
*   **O'lchamga javob beruvchi (Responsive) emas, balki qat'iy o'lchamda:** Dizayn asosan bir xil ko'rinishni saqlash uchun qat'iy o'lchamlarda yaratilgan.
*   **Faqat bitta fayl:** Barcha HTML, CSS va JavaScript kodlari bitta `animated_clock_index.html` faylida birlashtirilgan.
*   **Minimal JavaScript:** Faqat vaqtni olish va CSS o'zgaruvchilarini yangilash uchun ishlatiladi.
*   **Ingliz tilidagi izohlar:** Kodni tushunishni osonlashtirish uchun barcha izohlar ingliz tilida yozilgan.
