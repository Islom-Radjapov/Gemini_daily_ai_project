# blooming_css_flower_art

## Loyiha nomi: Blooming CSS Flower Art

## Tavsif
Bu loyiha sof CSS animatsiyalari yordamida yaratilgan, gullab ochilayotgan gul san'at asaridir. Sahifa rang-barang gullarni, mayin tebranayotgan poyani va barglarni namoyish etadi. Minimal JavaScript sahifaning to'liq yuklanganidan so'ng animatsiyalarni silliq boshlash uchun ishlatiladi, bu esa foydalanuvchi tajribasini yaxshilaydi. Maqsad, zamonaviy va chiroyli animatsiyalarni faqat CSS orqali qanday yaratish mumkinligini ko'rsatishdir.

## Qanday ishga tushirish mumkin?
1.  Yuqoridagi `index.html` fayl tarkibini kompyuteringizda `index.html` nomi bilan saqlang.
2.  `index.html` faylini istalgan zamonaviy veb-brauzerda (Chrome, Firefox, Safari va h.k.) oching.
3.  Sahifa yuklangandan so'ng, gulning sekin-asta ochilishi va mayin tebranishini kuzating.

## Xususiyatlar ro'yxati:
*   **Sof CSS San'ati**: Butun gul, uning barglari va poyasi faqat CSS yordamida shakllantirilgan.
*   **Gullash animatsiyasi**: Har bir gulbarg alohida animatsiya bilan ochilib, gullash effektini yaratadi.
*   **Mayin tebranish animatsiyasi**: Butun gul (poyasi va gullari) shamolda ohista tebranishni taqlid qiladi.
*   **Barglarning tebranishi**: Barglar ham alohida, mayin tebranish animatsiyasiga ega.
*   **Minimal JavaScript**: Animatsiyalar sahifaning to'liq yuklanganidan keyin boshlanishini ta'minlash uchun faqat bitta qator JavaScript kodi ishlatilgan.
*   **Zamonaviy va professional dizayn**: Estetik jihatdan yoqimli ranglar palitrasi va silliq animatsiyalar bilan yaratilgan.
*   **Bitta HTML fayl**: Barcha HTML, CSS va JavaScript birgina `index.html` faylida birlashtirilgan, bu esa loyihani tushunish va boshqarishni osonlashtiradi.
