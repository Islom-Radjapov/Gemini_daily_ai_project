# interactive_tree_visualization

## Project Name: Interactive Tree Visualization

## Description
This project is a simple, interactive web application designed to visualize hierarchical data structures, commonly known as trees. It leverages the HTML Canvas API to draw nodes and their connections (edges) in a clear, organized manner. A key feature is its basic interactivity: nodes change color when the mouse pointer hovers over them, providing immediate visual feedback. The entire application, including HTML structure, CSS styling, and JavaScript logic, is self-contained within a single HTML file for easy deployment and use.

## How to Run
To run this project, simply follow these steps:
1.  Save the provided `index.html` file to your local computer.
2.  Open the `index.html` file using any modern web browser (e.g., Chrome, Firefox, Edge, Safari).
The tree visualization will automatically load and be ready for interaction.

## Features
*   **Tree Data Visualization:** Displays a predefined hierarchical data structure (tree) graphically.
*   **HTML Canvas API:** Utilizes HTML Canvas for efficient and flexible drawing of all visual elements.
*   **Automatic Layout:** Nodes are automatically positioned using a simplified tree layout algorithm that aims to center parent nodes above their children, enhancing readability.
*   **Dynamic Centering:** The entire tree visualization is dynamically centered horizontally on the canvas, regardless of its width.
*   **Interactive Hover Effect:** When the mouse pointer hovers over a node, its color changes to provide visual feedback, indicating it's an interactive element.
*   **Single File Deployment:** All necessary code (HTML, CSS, JavaScript) is embedded within a single `index.html` file, making it incredibly portable and easy to share.
*   **Clean and Modern Design:** Features a minimalistic design with clear typography, subtle colors, and shadows for a professional aesthetic.
