# simple_pong_game

## Project Name: Simple Pong Game

## Project Description
This is a classic Pong game implemented using HTML5 Canvas and JavaScript. It's a two-player (one human, one AI) game where the objective is to hit the ball past your opponent's paddle. The game is designed to be fully functional, self-contained within a single HTML file, and adheres to modern web development best practices for a simple project.

## How to Run
1.  **Save the file:** Copy the entire content provided below into a new file named `index.html`.
2.  **Open in browser:** Double-click the `index.html` file, or drag and drop it into any modern web browser (Chrome, Firefox, Edge, Safari).
3.  **Play:**
    *   Use the **'W'** key to move your paddle up.
    *   Use the **'S'** key to move your paddle down.
    *   The computer opponent (on the right) will automatically try to hit the ball.
    *   First player to reach 5 points wins.
    *   Press **'R'** at any time to reset the game, or after the game ends.

## Features List
*   **Single HTML File:** All HTML, CSS, and JavaScript are bundled into one `index.html` file for easy deployment and portability.
*   **HTML5 Canvas:** Utilizes the Canvas API for all game rendering.
*   **Classic Pong Gameplay:** Implements core Pong mechanics including ball movement, paddle movement, and collision detection.
*   **Player Control:** Move the left paddle up and down using 'W' and 'S' keys.
*   **Basic AI Opponent:** A simple computer opponent that attempts to intercept the ball.
*   **Scoring System:** Tracks scores for both the player and the computer.
*   **Game Over Screen:** Displays a winner message and prompts for a reset.
*   **Responsive Ball Speed:** Ball speed slightly increases after each paddle hit, making the game progressively challenging.
*   **Clean Design:** Simple, dark theme with contrasting elements for clear visibility.
*   **Reset Functionality:** Allows resetting the game at any time or after a win/loss.
*   **English Comments:** All code comments are in English for better understanding.
