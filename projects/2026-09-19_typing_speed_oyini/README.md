# Typing Speed Game

## Loyiha nomi: Typing Speed Game

### Tavsif
Ushbu loyiha HTML5 Canvas yordamida yaratilgan oddiy terish tezligi o'yinidir. Foydalanuvchilar ekranda ko'rsatilgan so'zlarni tez va to'g'ri terish orqali o'zlarining terish tezligi va aniqligini sinab ko'rishlari mumkin. O'yin aniq va oqlangan foydalanuvchi interfeysini taqdim etadi va bitta HTML faylda to'liq ishlaydi.

### Qanday ishga tushirish mumkin?
1.  Yuqoridagi `index.html` faylining tarkibini kompyuteringizda `index.html` deb nomlangan faylga saqlang.
2.  `index.html` faylini istalgan zamonaviy veb-brauzerda (Chrome, Firefox, Edge va h.k.) oching.
3.  O'yin boshlash ekranida "Click anywhere to start!" yozuvini bosish orqali o'yinni boshlang.

### Xususiyatlar
*   **HTML5 Canvas asosida:** Barcha grafiklar va foydalanuvchi interfeysi Canvas yordamida chiziladi.
*   **To'liq bitta faylda:** Barcha HTML, CSS va JavaScript kodlari `index.html` faylida inline tarzda joylashgan.
*   **Tezlik va aniqlikni o'lchash:** WPM (Words Per Minute - daqiqasiga so'zlar) va Accuracy (aniqlik) ballari hisoblanadi.
*   **Vaqt cheklovi:** O'yin 60 soniya davom etadi.
*   **Real vaqt rejimida fikr-mulohazalar:** Terilgan harflar to'g'ri bo'lsa yashil, noto'g'ri bo'lsa qizil rangda ko'rsatiladi.
*   **Kengaytirilgan so'zlar ro'yxati:** O'yinda ishlatiladigan so'zlarning katta ro'yxati mavjud bo'lib, har bir o'yinda tasodifiy tartibda tanlab olinadi.
*   **O'yin holatlari:** Boshlash, o'ynash va o'yin tugashi holatlari o'rtasida silliq o'tish.
*   **Toza va zamonaviy dizayn:** Minimalistik, qorong'u rejimli vizual uslub.
*   **Hech qanday qo'shimcha kutubxonalar:** Loyiha faqat vanilla JavaScript va brauzerning standart API'laridan foydalanadi.
