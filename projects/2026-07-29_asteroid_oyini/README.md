# asteroid_game

This is a classic arcade-style Asteroid game implemented entirely using HTML5 Canvas, JavaScript, and CSS within a single HTML file. Navigate your spaceship, shoot down incoming asteroids, and survive for as long as possible!

## Features

*   **Responsive Controls**: Use arrow keys for movement and spacebar to shoot.
*   **Dynamic Asteroids**: Asteroids break into smaller pieces when hit, providing escalating challenges.
*   **Player Lives & Score**: Track your progress and aim for a high score.
*   **Invulnerability System**: A brief period of invulnerability after taking damage or spawning.
*   **Edge Wrapping**: All game objects (spaceship, asteroids, bullets) wrap around the screen boundaries, creating a seamless play area.
*   **Progressive Levels**: The game increases in difficulty as you clear asteroid waves.
*   **Game Over Screen**: Clear indication when your lives run out, with an option to restart.
*   **Modern Styling**: Uses a pixel-art-style font for an authentic retro arcade feel.

## How to Run

1.  Save the entire content below as a single HTML file (e.g., `asteroid_game.html`).
2.  Open the `asteroid_game.html` file in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.).

## Controls

*   **Arrow Up (↑)**: Thrust the spaceship forward.
*   **Arrow Left (←)**: Rotate the spaceship counter-clockwise.
*   **Arrow Right (→)**: Rotate the spaceship clockwise.
*   **Spacebar**: Fire a laser bullet from the spaceship.
